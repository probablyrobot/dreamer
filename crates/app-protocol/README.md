# dreamer-app-protocol

The protocol between [Dreamer](https://github.com/probablyrobot/dreamer)'s app host and an app process: JSON
lines carrying the app's view tree, its events, and its calls.

Most programs use it through [`dreamer-sdk`](https://crates.io/crates/dreamer-sdk).
See the [app protocol](https://github.com/probablyrobot/dreamer/blob/main/docs/app-protocol.md).
