# dreamer-view-tree

An app's view in [Dreamer](https://github.com/probablyrobot/dreamer) as a keyed tree of host components, with
keyed diffs between versions. The desktop draws the tree natively and the app
host draws it as a terminal UI.

Most programs use it through [`dreamer-sdk`](https://crates.io/crates/dreamer-sdk).
