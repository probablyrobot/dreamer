# dreamer-api

The typed API of [Dreamer](https://github.com/probablyrobot/dreamer): the generated records, the method table,
and dispatch that the desktop, the CLI, extensions, and apps share. It also
carries the Luau module and TypeScript declarations generated from the same
schema.

Most programs use it through [`dreamer-sdk`](https://crates.io/crates/dreamer-sdk).
See [grants](https://github.com/probablyrobot/dreamer/blob/main/docs/grants.md) for what each call may do.
