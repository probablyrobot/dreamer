# Architecture decision records

Short records of decisions that change or fix the architecture, with the
evidence behind them.

- File name: `NNNN-short-title.md`, numbered in order. Numbers are never reused.
- Status is one of `proposed`, `accepted`, `superseded by NNNN`.
- Keep each record short: context, decision, evidence, consequences.
- A record that resolves a feasibility gate includes the commands run, the
  platforms, and the measured results, or says plainly what was not run.

Template: [`0000-template.md`](0000-template.md).
